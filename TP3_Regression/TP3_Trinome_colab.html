Q3 · Découper et standardiser

[7]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.20, random_state=42
)

scaler = StandardScaler()
X_train_std = scaler.fit_transform(X_train)   # fit uniquement sur le train
X_test_std = scaler.transform(X_test)

print("Entraînement :", X_train_std.shape)
print("Test :", X_test_std.shape)

Entraînement : (160, 5)
Test : (40, 5)

Réponse : on obtient 160 maisons pour l'entraînement et 40 pour le test.

Intérêt de la standardisation : les variables ont des échelles très différentes (surface ≈ 100, garage = 0 ou 1). StandardScaler ramène chaque variable à une moyenne 0 et un écart-type 1, ce qui : - rend la descente de gradient stable et rapide (un même pas eta0 convient à toutes les variables) ; - rend les coefficients comparables entre eux.

Le scaler est ajusté (fit) uniquement sur l'entraînement, puis appliqué au test avec transform, pour éviter toute fuite d'information du test vers le modèle.

V. Expérimentations

Q10 · Étudier le taux d'apprentissage de SGDRegressor

[15]
essais = []
for eta in [0.0001, 0.001, 0.01]:
    modele = SGDRegressor(
        loss="squared_error", penalty=None,
        learning_rate="constant", eta0=eta,
        max_iter=2000, tol=None, random_state=42
    )
    modele.fit(X_train_std, y_train)
    pred = modele.predict(X_test_std)
    essais.append({
        "eta0": eta,
        "MAE": mean_absolute_error(y_test, pred),
        "RMSE": np.sqrt(mean_squared_error(y_test, pred)),
        "R²": r2_score(y_test, pred)
    })
print(pd.DataFrame(essais).round(4))

     eta0      MAE     RMSE      R²

1  0.0010  11.6138  14.1744  0.9488
2  0.0100  12.0906  14.5710  0.9459

Réponse :

eta0 MAE RMSE R²
0.0001 11,5964 14,1589 0,9489
0.001 11,6138 14,1744 0,9488
0.01 12,0906 14,5710 0,9459

Le taux d'apprentissage eta0 fixe la taille des pas de la descente de gradient. Avec 2000 époques, les trois valeurs convergent ; le plus petit pas (0.0001) donne la meilleure RMSE, quasiment identique à LinearRegression. Avec un pas plus grand (0.01), le modèle oscille davantage autour du minimum, d'où une erreur légèrement plus élevée. Un pas trop petit avec peu d'époques ralentirait au contraire l'apprentissage.

RMSE sans standardisation : 30492401757958.508
[17]
modele_brut2 = SGDRegressor(
    loss="squared_error", penalty=None,
    learning_rate="constant", eta0=0.00001,
    max_iter=2000, tol=None, random_state=42
)
modele_brut2.fit(X_train, y_train)
pred_brut2 = modele_brut2.predict(X_test)
print("eta0=0.00001 -> RMSE :", round(np.sqrt(mean_squared_error(y_test, pred_brut2)), 3))
print("               R²   :", round(r2_score(y_test, pred_brut2), 4))

eta0=0.00001 -> RMSE : 23.401
               R²   : 0.8605

Réponse : sans standardisation et avec eta0 = 0.01, l'apprentissage diverge : RMSE ≈ 3,05·10¹³, les poids explosent car les variables de grande échelle (surface, âge) produisent des gradients énormes.

Avec eta0 = 0.00001, les pas deviennent assez petits pour éviter la divergence : le modèle converge vers RMSE = 23,40 et R² = 0,86, mais reste nettement moins bon qu'avec les données standardisées (RMSE 14,57), car un seul pas ne convient pas à des variables d'échelles si différentes. La standardisation est donc indispensable pour SGD.

Q12 · Suivre l'apprentissage du modèle

[18]
modele_suivi = SGDRegressor(
    loss="squared_error", penalty=None,
    learning_rate="constant", eta0=0.01,
    random_state=42
)
mse_history = []
for epoque in range(100):
    modele_suivi.partial_fit(X_train_std, y_train)
    pred_train = modele_suivi.predict(X_train_std)
    mse_history.append(mean_squared_error(y_train, pred_train))

plt.plot(range(1, 101), mse_history)
plt.xlabel("Nombre d'époques")
plt.ylabel("MSE d'entraînement")
plt.title("Évolution de l'erreur pendant l'apprentissage")
plt.grid(alpha=0.3)
plt.show()
print("MSE époque 1 :", round(mse_history[0], 2), "| époque 100 :", round(mse_history[-1], 2))

MSE époque 1 : 2316.32 | époque 100 : 191.86

Réponse : la MSE d'entraînement diminue très fortement dès les premières époques (2316 après la 1ʳᵉ époque), puis se stabilise autour de 192 jusqu'à la 100ᵉ époque, avec de très petites fluctuations. Le modèle apprend rapidement et a convergé après quelques époques : continuer l'entraînement n'apporte plus d'amélioration.

VI. Compte rendu

1. Données utilisées — 160 maisons pour l'entraînement et 40 pour le test (80 % / 20 %). Le modèle utilise 5 variables explicatives.

2. Paramètres du modèle — LinearRegression donne 5 coefficients et 1 constante : un coefficient pour chacune des 5 variables, plus l'ordonnée à l'origine (230,39).

3. Qualité des prédictions —

Modèle MAE RMSE R²
LinearRegression 11,596 14,158 0,9489
SGDRegressor 12,091 14,571 0,9459

Avec LinearRegression, la MAE de 11,6 signifie qu'on se trompe en moyenne d'environ 11,6 milliers sur le prix, et le R² de 0,949 indique que le modèle explique près de 95 % de la variabilité des prix.

4. Comparaison — LinearRegression donne les meilleures prédictions : RMSE de 14,158 contre 14,571 pour SGDRegressor (et R² 0,9489 contre 0,9459).

5. Lecture du graphique — la droite pointillée représente y_prédit = y_réel (prédiction parfaite). Un point situé au-dessus de cette droite indique une surestimation du prix.


Figure 1 – Prix réels vs prix prédits

6. Taux d'apprentissage — eta0 = 0.0001 donne la plus faible RMSE. RMSE obtenues : 14,1589 (0.0001) ; 14,1744 (0.001) ; 14,5710 (0.01).

7. Standardisation — sans standardisation, avec eta0 = 0.01, SGDRegressor diverge (RMSE ≈ 3,05·10¹³). Avec eta0 = 0.00001 il converge mais reste moins précis (RMSE = 23,40 ; R² = 0,86).

8. Évolution de l'erreur — l'erreur diminue fortement puis se stabilise autour de 192 : le modèle a convergé rapidement.


Figure 2 – MSE d'entraînement

9. Nouvelle maison — LinearRegression : 307,64 milliers d'unités monétaires ; SGDRegressor : 309,18 milliers. Les deux prédictions sont très proches.
